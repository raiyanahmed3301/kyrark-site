Application security · OWASP Top 10:2025

Test the risks in your application’s real attack paths

We use the current OWASP Top 10 as an awareness and scoping guide, then tailor test coverage to your application, architecture and written scope.

A01:2025

Broken Access Control

Review role and object permissions, tenant boundaries, direct API access and server-side request paths where applicable.

A02:2025

Security Misconfiguration

Check security-relevant defaults, exposed services, access settings, security headers and overly detailed errors in scope.

A03:2025

Software Supply Chain Failures

When source and build systems are in scope, review dependency exposure, provenance, update paths and CI/CD controls.

A04:2025

Cryptographic Failures

Examine protection of sensitive data in transit and at rest, and the use and handling of keys, secrets and cryptographic operations.

A05:2025

Injection

Test untrusted input reaching interpreters and browsers, including query, command, template and cross-site scripting paths.

A06:2025

Insecure Design

Assess trust boundaries, abuse cases, business rules and security controls that should be built into the design.

A07:2025

Authentication Failures

Review sign-in, account recovery, multi-factor flows, session lifecycle and protections against credential attacks.

A08:2025

Software or Data Integrity Failures

Check whether code, updates, serialized data and other trusted artifacts are validated before use.

A09:2025

Security Logging and Alerting Failures

Review whether relevant security events are recorded safely, monitored and connected to actionable alerts when those controls are in scope.

A10:2025

Mishandling of Exceptional Conditions

Test error paths, timeouts, invalid states and resource failures for unsafe fallback behavior or incomplete operations.

Category names and ordering are from the OWASP Top 10:2025 by the OWASP Top 10 Team; the coverage examples above are Kyrark’s adaptation for assessment scoping under CC BY 3.0. Coverage depends on the agreed scope and available access; this mapping is a guide, not a certification or a promise that every category applies to every engagement.
